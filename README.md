# Aurum396 website

Static GitHub Pages site with editable content managed through Pages CMS.

## Editable content
- `content/site.json` — homepage copy and settings
- `content/places/*.json` — destinations
- `content/articles/*.json` — future Journal articles
- `assets/` — uploaded images
- `.pages.yml` — Pages CMS configuration

The public homepage is rendered from these content files. GitHub Pages republishes automatically after commits.
